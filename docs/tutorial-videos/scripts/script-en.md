# Israeli Retirement Planning — tutorial video script (English)

Total length: about 7:43 (measured from the recording).

## How to use it in Clipchamp

Do step 1 first. Then choose **one** of steps 2 and 3, not both, or there will be two voice-overs.

1. Create a new video in Clipchamp and import the clips from `output/en/` (see the table below). Add them to the timeline in that order.
2. Route A, ask Copilot: open the Generate a video panel, paste the whole of `prompt-en.txt` and check that the result uses these clips and this narration, not stock footage. If it does not, use Route B.
3. Route B, by hand: in Record & create → Text to speech, choose the voice for en-US and paste the "one block" text of each clip below, one per clip, placing each at the start of its clip. Then turn on captions in the Captions tab (choose the spoken language, Transcribe media).

Clipchamp cannot import an SRT file. `subtitles-en.srt` holds the same narration with timings, for other tools such as YouTube.

The README in the tutorial-videos folder explains each step in more detail.
