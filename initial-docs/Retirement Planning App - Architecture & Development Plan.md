# Retirement Planning App - Architecture & Development Plan
 
## Vision
 
Build a privacy-first retirement planning web application where all user financial data remains on the user's device by default.
 
Core principles:
 
- Privacy-first
- Local-first
- No required account creation
- No server-side storage
- No user tracking
- Easy backups and portability
- Free or near-free hosting
