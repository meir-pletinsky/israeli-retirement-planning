How to test

  1. Serve this file over http://localhost or HTTPS (a file:// page is not reliable for persistent permissions), e.g. python -m http.server 8080 in the folder, then open http://localhost:8080/fsa-persistent-permission-test.html.
  2. Click Pick folder, choose a test folder, and grant Edit access (needed for the write test).
  3. Close all tabs of this origin (or restart Edge), then open the page again.
  4. The page reads the stored handle and shows its permission state. If it's prompt, click Re-request permission. Look for the three-option prompt: Allow this time / Allow on every visit / Don't allow.
  5. Choose Allow on every visit, close all tabs again, reopen. If the state is now granted on load, without any prompt, the feature works.
  6. Optional: check edge://settings/content/fileEditing or the site-info (lock icon) popup to see the granted folder.
